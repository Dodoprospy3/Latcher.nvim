1. INTRODUCTION                                       *latcher-introduction*

Latcher shows a numbered hint ([1] .. [9]) in the top-right corner of every
visible, focusable window. Type a number to jump to that window. <Esc>
cancels.

Requires Neovim 0.10 or newer. Pure Lua, no dependencies, and it never
modifies buffer contents.

==============================================================================
2. SETUP                                                  *latcher-setup*

With lazy.nvim: >lua
  {
    "Dodoprospy3/Latcher.nvim",
    lazy = false,
    opts = {},
    keys = {
      { "<leader>w", "<cmd>Latcher<cr>", desc = "Jump to window by number" },
      { "<leader>W", "<cmd>LatcherReassign<cr>", desc = "Assign window number" },
    },
  }
<
The plugin calls `setup()` automatically from plugin/latcher.lua, so calling
it manually is optional.

==============================================================================
3. COMMANDS                                            *latcher-commands*

:Latcher                                                        *:Latcher*
  Show hints and wait for a digit 1-9. <Esc> or <C-c> cancels. Invalid keys
  are ignored while waiting.

:LatcherReassign                                        *:LatcherReassign*
  Assign the next typed digit 1-9 to the current window. If another window
  owns that number it loses it, and shows no hint until it wins one again.

==============================================================================
4. NUMBERING                                          *latcher-numbering*

Eligible windows are ordered by buffer number, then window id, and the first
nine receive numbers 1-9. Manual assignments from |:LatcherReassign| always
win and persist for the Neovim session.

When a manual assignment takes a number from another window, that window is
"stripped": it shows no hint and nothing else shifts or swaps.

==============================================================================
5. OPTIONS                                              *latcher-options*

`require("latcher").setup({})` accepts an empty table. Unknown keys raise an
error instead of being silently ignored; the table is reserved for future
options.

==============================================================================
6. LUA API                                                  *latcher-api*

require("latcher").setup({opts})     Initialize commands and highlight.
require("latcher").start()           Same as |:Latcher|.
require("latcher").reassign()        Same as |:LatcherReassign|.

==============================================================================
7. HIGHLIGHTS                                        *latcher-highlights*

LatcherHint  Default: white bold text on a red background. Override it with: >lua
  vim.api.nvim_set_hl(0, "LatcherHint", {
    fg = "#ffffff",
    bg = "#d20f39",
    bold = true,
  })
<
